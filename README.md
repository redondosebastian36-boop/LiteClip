\# LiteClip



A lightweight screen and clip recording utility for Windows built with \*\*Python\*\*, \*\*FFmpeg\*\*, and \*\*Tkinter\*\*, designed to stay out of your way with global hotkeys and system tray integration.



\## Features

\- \*\*Global Hotkeys:\*\* Start and stop clip recording from anywhere with a configurable shortcut.

\- \*\*Audio \& Microphone Mixing:\*\* Capture system audio and/or microphone input with adjustable volume levels.

\- \*\*Custom Video Settings:\*\* Choose preset or custom resolutions and FPS, quality profiles, and target monitor.

\- \*\*Multi-Language \& Themes:\*\* Switch UI language (English, Spanish, French, Chinese, Japanese) and color themes.

\- \*\*Background \& Tray Mode:\*\* Run quietly in the system tray with optional background behavior on window close.



\## Requirements

\- \*\*FFmpeg\*\* installed and available in system `PATH` (or alongside the app).

\- Python packages (`pystray`, `pillow`, `keyboard`, `pyinstaller` if building an `.exe`).
